# 부산진고 학교생활 정보 포털

부산진고 학생들이 학교생활에 필요한 정보를 보다 편리하게 확인할 수 있도록 개발한 웹 서비스입니다.

## 개발 목적

급식, 학사일정 등 학교생활에 필요한 정보가 여러 곳에 분산되어 있어 학생들이 정보를 확인하는 데 불편함이 있다고 생각했습니다.

이를 개선하기 위해 필요한 정보를 하나의 웹페이지에서 확인할 수 있는 학교생활 정보 포털을 제작했습니다.

## 주요 기능

- NEIS Open API를 활용한 급식 자동 조회
- 날짜별 급식 조회
- 월별 급식 조회
- 급식 정보 오류 및 변경 상황을 대비한 수동 수정 기능
- NEIS Open API를 활용한 학사일정 조회
- 이전 달 / 이번 달 / 다음 달 학사일정 조회
- API 응답 지연 시 무한 로딩을 방지하는 예외 처리
- 모바일 환경을 고려한 웹페이지 구성

## 사용 기술

- HTML
- CSS
- JavaScript
- NEIS Open API
- GitHub
- GitHub Pages

## 개발 과정

1. 학교생활 정보 통합
학생들이 자주 확인하는 급식과 학사일정을 하나의 페이지에서 확인할 수 있도록 기본 웹페이지를 설계했습니다.

2. 급식 정보 자동화
매달 급식 정보를 직접 입력하는 방식은 지속적인 관리가 필요하다는 문제가 있었습니다.

이를 해결하기 위해 NEIS Open API를 이용하여 날짜에 따라 부산진고등학교의 급식 정보를 자동으로 가져오도록 구현했습니다.

3. 예외 상황을 고려한 급식 수정 기능
NEIS 정보가 실제 학교 상황과 다르거나 급식이 갑자기 변경되는 경우를 고려하여 특정 날짜의 급식을 직접 수정할 수 있는 수동 override 기능을 추가했습니다.

4. 학사일정 자동 조회
급식과 마찬가지로 NEIS Open API를 이용하여 학교의 월별 학사일정을 자동으로 불러오도록 구현했습니다.

개발 과정에서 API 요청 후 로딩 상태가 계속 유지되는 문제가 발생하여 요청 시간 제한과 오류 처리 기능을 추가했습니다.

5. 웹 서비스 공개 배포
완성된 웹페이지를 GitHub 저장소에서 관리하고 GitHub Pages를 이용해 별도의 프로그램 설치 없이 학생들이 링크를 통해 접속할 수 있도록 공개 배포했습니다.
